# SwarmCore Agent 项目简历

项目背景：
面向 Agent 系统在复杂流程编排、长任务运行、故障恢复、安全控制和多协议接入方面的共性需求，建设协议无关的多 Agent 编排与耐久执行底座，将声明式策略转化为可控制、可恢复、可审计的工程化执行过程。

【架构设计】：采用领域、应用、适配与运行时分层架构，统一 REST、MCP 和 Web 控制入口的应用服务、权限、幂等及结果契约，避免形成多套执行链路。

【策略编排】：设计 SwarmSpec 声明式规格与编译器，完成 Schema、语义、引用和策略校验，将 Agent、Tool、路由、循环、并行、汇聚、归并、审批及输入节点编译为不可变执行计划。

【耐久执行】：基于 Temporal 构建确定性 Workflow 和完整运行状态机，支持并发、重试、超时、暂停、恢复、取消、人工审批、补充输入及失败补偿，保障长任务在进程故障后继续执行。

【一致保障】：通过事务 Outbox、严格命令序列、请求幂等、事件序号和 Tool effect ID，可靠衔接数据库、执行引擎与事件系统，并为外部副作用提供幂等、补偿或人工恢复机制。

【开放适配】：使用 Adapter 隔离具体 Agent SDK，通过 Model Gateway 和 Tool Gateway 统一模型路由、工具调用、凭据注入、风险分级、超时与预算控制，避免核心调度绑定单一框架或 Provider。

【安全治理】：建立 tenant/project 数据边界，结合 OIDC/JWT、OPA、Vault、PostgreSQL RLS、mTLS、短期能力令牌和隔离沙箱，实现身份认证、策略授权、Secret 管理、风险审批及资源配额控制。

【观测交付】：贯通运行、Workflow、模型、Tool、Artifact 和 Webhook 的 Trace、Metrics、结构化脱敏日志与只追加审计，支持状态查询、事件历史补读、SSE 实时推送、签名 Webhook 和 Artifact 交付。

项目结果：
形成“策略接入—校验编译—耐久调度—Agent/Tool 执行—人工与策略控制—状态事件持久化—结果交付”的完整闭环；核心耐久执行、人工控制及受控 Tool、Router、Loop 已完成本地验证，REST/MCP、能力适配、安全治理和可观测链路已完成本地实现。当前成果定位为本地候选版本，生产同构环境下的真实 Provider、安全隔离、故障恢复、容量及完整 CI 资格仍在推进。
